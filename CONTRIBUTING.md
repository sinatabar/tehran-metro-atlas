# Contributing

Open an issue in Persian or English with the entity ID, what changed, the source URL, its publication date and the specific claim it supports. Differing spellings, claims about service status and a proposed relocation should each be identifiable. Include dates and locality. Use original-language names where possible.

For a data pull request, work from the reviewed inputs. Provide independent evidence for passenger operation and geographic location. Include license/attribution details and old/new source IDs, retain contradictory reports, regenerate the data and include the Git diff of the products. Put incomplete proposals in the inventory with null geometry. For code contributions, include the affected Persian and English states and run the README checks. CI validates changes before deployment.
