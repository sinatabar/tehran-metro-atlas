# Architecture decisions

**One static origin.** React, strict TypeScript and Vite produce static files served by GitHub Pages. A separate build emits searchable Persian and English HTML for each entity, canonical and language-alternate links, a sitemap, JSON-LD and an Open Graph preview drawn from the reviewed railway paths. Valid direct links work when JavaScript is disabled. No accounts, API keys, server-side database, analytics or live geocoder are required.

**On-device GIS.** MapLibre GL JS renders local WGS84 GeoJSON and a generalized OpenStreetMap basemap. The same app bundle serves in both directions. Local Vazirmatn and DM Sans fonts and browser-shaped collision-filtered labels avoid remote glyph and RTL services. Zoom reveals station labels. React loads the heavy map module only on the map page. Readers with unavailable WebGL can use searchable directories and downloadable datasets. Default network statistics come from the validated release.

**Rendering and internationalization.** The reviewed facts own bilingual names, notes and aliases. The user interface uses a typed two-locale model with the browser's Intl calendar and number support. CSS logical properties, shared tokens and Lucide icons support RTL/LTR, light/dark and mobile layouts. Plain CSS fits the bounded design system and avoids another configuration and build layer. Future locales would warrant ICU message catalogs.

**Data processing.** Python's standard library handles deterministic joins, quality gates and exports. pyosmium reads regional OSM PBFs; Shapely/GEOS checks geometry and GIS interchange. Native WGS84 coordinates need no reprojection for web use. GeoPandas, Pandas, PyProj and a backend add no required operation to these transformations. Documented inputs and direct object references allow future QGIS and GeoPackage workflows.

**Connectivity.** One origin serves the page, fonts, code, workers, geographic data and downloadable GIS files. The optional offline copy caches only this project's versioned build and both map datasets after a reader opts in. It needs one successful online save and browser storage. External source articles, exports and unseen third-party pages require connectivity or a separate download. Source evidence remains available if public map tile servers fail because this application makes no tile requests to them. The source tree builds on a laptop and the static output can be mirrored. Iranian ISP reachability of the chosen Pages host remains untested; CDN availability and a successful test from Europe do not establish it. [Internet Society's Iran connectivity observations](https://pulse.internetsociety.org/en/shutdowns/blackout-in-iran/) · [OSMF tile policy](https://operations.osmfoundation.org/policies/tiles/)

**Dependency selection.** Current stable releases were resolved from npm on 24 November 2026 after checking official Vite, React and MapLibre guides. Exact versions are pinned in package.json and the lockfile. The MapLibre v6 worker uses the bundler-recommended same-origin worker URL.
