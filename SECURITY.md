# Security

Report a security problem privately using the repository owner's GitHub contact or private vulnerability reporting if enabled. Include the affected release, browser and a concise description. Keep personal information and credentials out of reports. Ordinary station corrections and source disagreements belong in public data issues.

Publication uses GitHub's job-scoped Pages and OIDC permissions. Source monitoring is read-only, stores observations as workflow artifacts and has no deployment permission. Dependencies are pinned. The static app renders source text through React or escaped static templates and has no login, tracking or user-data collection.
